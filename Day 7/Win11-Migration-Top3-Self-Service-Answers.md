# Self-Service Answers for Top 3 Win11 Migration Themes

## 1) AVD Sign-In / Account Lockouts
Please try these quick steps:
1. Close AVD completely, then open it again and sign in once using your full work email (for example: name@company.com). Make sure Caps Lock is off.
2. If it still fails, wait 15 minutes and try one more time. Do not keep retrying quickly, because this can extend the lockout.

If you still cannot sign in after this, contact the service desk. Share: the exact error message shown, the time it happened, your username, and whether you used VPN or office network.

## 2) OneDrive Missing/Inaccessible Files
Please try these quick steps:
1. Open OneDrive and check that you are signed in with your work account. Then click sync/resume if it is paused.
2. In File Explorer, open OneDrive and use the search box to find the missing file name. Also check the OneDrive Recycle Bin in your browser.

If files are still missing, contact the service desk. Share: 2-3 missing file names, the folder path where they should be, when you last saw them, and a screenshot of any OneDrive warning icon.

## 3) Shared Drive (S:) Access Issues
Please try these quick steps:
1. Disconnect and reconnect to VPN (if you are remote), then wait 1-2 minutes and open the S: drive again.
2. Sign out of Windows, sign back in, and try S: drive from File Explorer one more time.

If S: drive still does not open, contact the service desk. Share: the exact message you see (for example “permission denied”), your location (office or remote), the time tested, and one folder name you were trying to access.
